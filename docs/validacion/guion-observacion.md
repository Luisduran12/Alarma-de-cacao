# Guion de observación (10 minutos por productor)

**Reglas del observador:**
- Lea las tareas tal cual; **no ayude** ni señale botones. Si el productor se atasca más de 1 minuto, dígale "no pasa nada,
  sigamos con la siguiente" y anote **"no pudo"**.
- Pídale que piense en voz alta: "cuénteme qué está pensando mientras lo hace".
- Silencio y paciencia. Anote lo que hace, no lo que usted cree que quiso hacer.
- Nunca le diga "está bien" ni "está mal": solo "gracias".

**Antes (1 min):** consentimiento firmado. Teléfono con la app abierta en la pantalla de inicio, lote de ejemplo creado,
sin ayuda previa. Tenga un cronómetro.

| Min | Tarea (lo que se le dice) | Qué observar | Resultado: **S**olo / con **A**yuda / **N**o pudo | Segundos | Notas |
|---|---|---|---|---|---|
| 0–1 | "Cuénteme qué cree que hace esta aplicación." *(solo mirando la pantalla de inicio)* | ¿Entiende que es para el beneficio del cacao? ¿Qué toca primero? | | | |
| 1–2 | "Cree un lote nuevo para empezar a fermentar." | ¿Encuentra el botón? ¿Entiende la plantilla de 144 horas? | | | |
| 2–3 | "Haga que suene una alarma de prueba." *(ícono de campana)* | ¿Lo encuentra? ¿Entiende que suena a los 10 s? | | | |
| 3–5 | "Suena la alarma de volteo. Anote que la masa está a 45 grados y la humedad en 80." | ¿Abre la notificación? ¿Entiende cada campo? ¿Se equivoca de campo? | | | |
| 5–6 | "Diga la observación hablando, sin escribir." *(micrófono)* | ¿Ve el micrófono? ¿Entiende el aviso de la voz? ¿Funcionó sin internet? | | | |
| 6–7 | "Muéstreme cómo ve la curva de temperatura del lote." | ¿Encuentra la curva? ¿Entiende la banda fuera de rango? | | | |
| 7–8 | "Pregunte en la guía: ¿cada cuánto se voltea el cacao?" *(sin internet)* | ¿Entiende que es una guía y no un técnico? ¿Le sirve la respuesta? | | | |
| 8–9 | "La letra le queda pequeña: haga que se vea más grande." | ¿Encuentra Ajustes? ¿Entiende "Letra y colores"? | | | |
| 9–10 | "Imagine que quiere borrar todo lo que guardó la aplicación." *(no lo confirme)* | ¿Lo encuentra? ¿Entiende la advertencia? Pare antes de confirmar. | | | |

**Cierre (1 min, sin sumar a los 10):** "¿Qué fue lo más difícil?" "¿Qué le cambiaría?" "¿Qué no entendió?" Anote sus
palabras textuales. Después, la [encuesta](encuesta-usabilidad.md).

## Qué mirar siempre
- Dónde duda, dónde toca lo que no era, dónde se ríe o suspira, dónde acerca el teléfono a la cara (letra pequeña).
- Si usa el sol en la cara: ¿se ve la pantalla? (probar en un lugar con luz del día si se puede).
- Si llegó una alarma real con la app cerrada (si el teléfono lo permite) y qué hizo.

## Qué anotar de cada tarea
Solo **S / A / N**, los segundos y una frase de lo que ocurrió. Eso se pasa a [`plantilla-resultados.md`](plantilla-resultados.md).
